# HappyKidz

HappyKidz is a colourful edutainment website made for children. It brings learning and play together in one friendly space, with interactive learning activities, mini games, videos, a gallery, and a gift section.

## Features

- **Learning activities** — spelling, calculators, quizzes, and other kid-friendly exercises
- **Mini games** — simple games designed for fun and engagement
- **Video section** — cartoons and songs for children
- **Gift section** — a playful lucky-draw style activity
- **Favourite picker** — lets children choose a favourite activity image
- **Theme toggle** — light and dark colour options
- **Responsive layout** — designed to work across desktop and mobile screens

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts

## Project Structure

```text
HappyKidz/
├── index.html              # GitHub Pages entry page
├── home/                   # Main HappyKidz home page
├── learnGallery/           # Learning activity menu
├── learn/                  # Individual learning activities
├── gamesGallery/           # Games menu
├── VideoGallery/           # Video gallery
├── Gift/                   # Gift activity
├── images/                 # Image assets
└── video/                  # Video assets
```

## Run Locally

Open `index.html` in a browser, or open the project with the **Live Server** extension in VS Code.

## Notes

This is a static front-end project. The login and registration interface is visual only and does not save user accounts or connect to a database.
